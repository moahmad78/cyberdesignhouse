# cyberdesignhouse

> **Cyber Design House** · The modern technology and digital growth arm of **VoometDesign** (Est. 2010), Bangalore, India.

A high-performance, 3D animated marketing and consultation platform built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Three.js**.

---

## 🚀 Key Features

* **3D Interactive Hero**: Procedural dual-material faceted CD crystal mark with mouse parallax, physics shards, and ambient rim lighting.
* **Pinned 3D Services Showcase**: Interactive multi-tab showcase for the 4 core disciplines (Web Development, App Development, SEO, Digital Marketing) with real-time 3D models.
* **Technology Orbit & Advantage Cards**: GPU-accelerated interactive tech stack visualization and tilt cards.
* **Comprehensive Service Pages**: Full dynamic routing (`/services/[slug]`) with technical deliverables, capabilities, processes, and FAQs.
* **Lead Conversion & Consultation**: 2-column contact system (`/contact`) with multi-discipline selection, validation, honeypot anti-spam, and confetti delight.
* **SEO & Compliance**: Built-in OpenGraph metadata, Schema.org JSON-LD structured data (`Organization`, `ProfessionalService`, `Service`, `FAQPage`, `BreadcrumbList`), `sitemap.xml`, and `robots.txt`.
* **WCAG 2.1 AA Accessibility & Smooth Scrolling**: Skip-to-content links, high contrast ratios, Lenis inertia scrolling, and `prefers-reduced-motion` compliance.

## 🛠 Tech Stack

* **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
* **Language**: [TypeScript](https://www.typescriptlang.org/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **3D Graphics**: [Three.js](https://threejs.org/)
* **Smooth Motion**: [Lenis](https://github.com/darkroomengineering/lenis) & [GSAP](https://gsap.com/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Visual Identity**: Official Faceted CD Mark & Lockup by VoometDesign

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live website.

### 3. Build for Production
```bash
npm run build
npm start
```
